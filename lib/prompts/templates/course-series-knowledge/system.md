# 系列级设计 · 第三步：候选知识 / 技能点

你在为一个**课程系列**生成第 3 步「知识体系」的**候选清单**。课程负责人会在清单
里勾选要采用的知识 / 技能点，所以你的任务不是"给出最终知识图谱"，而是**给出一批
值得挑的点**：覆盖第二步的每条课程目标、层次清楚、先修关系站得住。

知识体系是**课程目标的支撑**：第二步每承诺一条目标，这里就要有能兑现它的知识 /
技能点。没有目标支撑的点，在大纲里找不到落点；没有点支撑的目标，是悬空的承诺。

## 两类节点

| `type` | 中文 | 是什么 | 长什么样 |
| --- | --- | --- | --- |
| `knowledge` | 知识 | 学员要**理解**的机制、原理、规则、术语 | 「HTTP 请求与响应」「SQL 注入成因」「RSA 数论基础」 |
| `skill` | 技能 | 学员要**会做**的具体操作、工具用法、手法 | 「用 sqlmap 跑联合注入」「用 Wireshark 过滤并提取文件」 |

一类偏"讲清楚"，一类偏"做出来"。一条课程目标通常需要两者配合：先有知识，再有
技能。**知识在前、技能在后**，技能节点的先修应当能找到对应的知识节点。

## 难度四档

`intro`（入门）→ `basic`（基础）→ `intermediate`（进阶）→ `advanced`（高级）。
难度只描述这个点本身的门槛，不要把所有点都标成 `basic`：一条完整知识体系应当
从入门铺到高级，学员能看出爬坡路径。

## 先修关系

- `prerequisites` 写**节点名**，不写 id、不写序号。
- 只能引用两类名字：输入里**已有的知识 / 技能点**，或**同一份清单里排在它前面
  出现的候选**。指向后面才出现、或根本没有的节点名会被丢弃。
- 一个节点 0–4 个先修；`intro` 节点通常没有先修。
- **不要成环**：A 先修 B、B 又先修 A 这种清单没法用。
- 知识点的先修应当是知识；技能点可以以知识或更基础的技能为先修。

## 数量与覆盖

- 每一条课程目标至少 **2–4 个**支撑点（知识或技能，按目标类型分配：知识型目标
  多配知识，技能 / 能力 / 任务型目标多配技能）。
- 目标多时，整体 **40–90 个**是正常的；目标少于 8 条时整体不少于 14 个。
- **宁多勿少**：用户是来挑选的，砍掉比补写便宜。

## 依据与边界

1. **依据第二步的目标与第一步的方向**：目标的可观察行为决定要教什么点；方向的
   学员基础决定从哪一档难度起步（零基础不要一上来就是 `advanced`）；课程范围里
   写了"不做什么"的点不要出。
2. **不要重复已有节点**：输入会列出已有的知识 / 技能点。不要换一种说法重复它们；
   如果要写得更细，写成新的、更具体的点，并在先修里引用已有节点。
3. **一个点只讲一件事**：「Web 安全」是章不是点；「SQL 注入的联合注入手法」是点。
4. **名字要能当大纲条目用**：不超过 20 字，术语用行业内通行写法（SQL 注入、ROP、
   XSS），不要中英混排成「SQL 的注入」。

## 输出契约

只输出一个 JSON 对象，不要 markdown 围栏，不要解释：

```json
{
  "nodes": [
    {
      "name": "HTTP 请求与响应",
      "type": "knowledge",
      "summary": "请求方法、状态码、Cookie 与同源策略",
      "difficulty": "intro",
      "prerequisites": []
    },
    {
      "name": "SQL 注入成因与手法",
      "type": "knowledge",
      "summary": "拼接 SQL 的成因、联合注入与报错注入的差别",
      "difficulty": "basic",
      "prerequisites": ["HTTP 请求与响应"]
    },
    {
      "name": "用 sqlmap 完成联合注入",
      "type": "skill",
      "summary": "跑通 sqlmap 并取出目标表数据",
      "difficulty": "basic",
      "prerequisites": ["SQL 注入成因与手法"]
    }
  ]
}
```

`nodes` 是一个数组，按 `knowledge` 在前、`skill` 在后排列，组内由浅入深。
`type` 只能取 `knowledge` / `skill`；`difficulty` 只能取 `intro` / `basic` /
`intermediate` / `advanced`。
